# Flat Price Prediction Project

Этот проект предназначен для автоматического сбора, обработки и анализа данных о квартирах с последующим прогнозированием их стоимости. В основе лежит пайплайн, включающий парсинг данных, обучение модели и API для предсказаний.

# Структура проекта

FlatPricePredictionProject/
│
├── data/  
│   ├── raw/  # Данные из парсинга  
│
├── models/  
│   ├── model.py   # Код для обучения и предсказания модели  
│   ├── preprocessing.py   # Вспомогательные функции  
│   ├── pipe/      # Папка для сохранения последней версии модели  
│
├── parsing/  
│   ├── scraper.py  # Скрипт для парсинга данных с сайта CIAN  
│
├── api/  
│   ├── api.py    # FastAPI сервер для предсказаний  
│   ├── requirements.txt  
│
├── dags/  
│   ├── dag.py  # DAG для управления процессами в Airflow  
│
├── docker-compose.yml  # Docker для API  
├── docker-compose.airflow.yml  # Docker для Airflow  

•  Парсер (scraper.py)
•	Собирает данные о квартирах с CIAN (цена, метраж, этаж, год постройки и т.д.).
•	Сохраняет данные в data/raw/.
•  Обучение модели (model.py)
•	Загружает собранные данные.
•	Выполняет предобработку (обнаружение пропусков, генерация новых фичей).
•	Обучает ML-модель для предсказания стоимости квартир.
•	Сохраняет модель в models/pipe/.
•  API (main.py)
•	Принимает JSON-запрос с параметрами квартиры.
•	Загружает последнюю версию модели.
•	Возвращает предсказанную цену.
•  Airflow (dag.py)
•	Автоматизирует процесс:
1.	Запуск парсера
2.	Обучение модели
3.	Обновление API
# Развертывание
1.	Запуск API
docker-compose up --build -d

После запуска API будет доступно на http://localhost:8000/docs
2.	Запуск Airflow
	docker-compose -f docker-compose.airflow.yml up --build -d
	Airflow доступен на http://localhost:8080/.
3.	Проверка DAG
Перейди в UI Airflow и найди flat_price_dag. Запусти его(автозапуск настроен на 19:00 каждый день)
