# Change foto backround

Этот проект представляет собой сервис для замены фона на изображениях. В основе лежит библиотека Rembg, которая использует предобученную MODNet – облегчённую U-Net-подобную нейросеть, специально разработанную для удаления фона.
Пользователь загружает два изображения (оригинал и новый фон), а сервис автоматически удаляет старый фон и подставляет новый.

Проект поддерживает API на FastAPI и веб-интерфейс на Gradio, а также легко разворачивается в Docker.

# Функционал

✅ Удаление фона с изображения.
✅ Замена фона на загруженное пользователем изображение.
✅ Работа через API (FastAPI) и веб-интерфейс (Gradio).
✅ Запуск в контейнере через Docker.

# Стек технологий

FastAPI – REST API.
Gradio – удобный веб-интерфейс.
Rembg (MODNet) – модель для удаления фона.
Pillow (PIL) – обработка изображений.
Docker – контейнеризация
# Развертывание
## Локально(без docker)
1. Установить зависимости
pip install -r requirements.txt

2. Запустить код
python app.py

## Запуск через Docker
1. docker-compose up --build
2. API будет доступно по адресу: http://localhost:8000
3. Gradio-интерфейс будет доступен по адресу: http://localhost:8000/gr/

## Postman
Открыть Postman.
Выбрать POST и ввести http://localhost:8000/change-background.
Перейти на вкладку Body → form-data.
Добавить два файла:
original – оригинальное изображение.
background – новый фон.
Нажать Send.
