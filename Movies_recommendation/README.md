# Movies Recommendation System

Этот проект представляет собой гибридную рекомендательную систему для сериалов, которая объединяет контентные признаки (описания, жанры, актёры, год выпуска) и использует векторное представление текстов (BERT) для вычисления схожести между сериалами.

# Функциональность

Пользователь вводит любимые сериал(ы).
Система анализирует их описания, жанры, актёров и год выпуска.
Выдаёт список наиболее похожих сериалов на основе комбинированного векторного представления.
Раз в неделю с помощью Apache Airflow обновляется база данных сериалов, а также пересчитывается матрица схожести.
API на FastAPI оборачивает всю логику в удобный сервис для интеграции.

# Используемые технологии

NLP: BERT для векторизации описаний сериалов
Фичи: жанры (one-hot encoding), год выпуска (нормализованный)
Рекомендации: Поиск ближайших сериалов с использованием косинусного расстояния
Парсинг данных: IMDb
Автоматизация: Apache Airflow (обновление данных раз в неделю)
API: FastAPI
Деплой: Docker + Docker Compose

# Как работает

Парсер IMDb собирает данные о популярных сериалах (описания, жанры, актёры, год и т. д.).
Векторизация:
Описания сериалов преобразуются в BERT-векторы.
Жанры кодируются как one-hot вектора.
Год выпуска нормализуется.
Формирование матрицы схожести сериалов (обновляется раз в неделю).
Рекомендации:
Получаем вектора для сериалов, введённых пользователем.
Вычисляем средний вектор и ищем N ближайших сериалов по косинусному расстоянию.
API (FastAPI) возвращает список сериалов, которые лучше всего подходят пользователю.

# Развертывание

1.	Запуск API

docker-compose up --build -d

После запуска API будет доступно на http://localhost:8000/

2.	Запуск Airflow

docker-compose -f docker-compose.airflow.yml up --build -d

Airflow доступен на http://localhost:8080/

3.	Проверка DAG

Перейди в UI Airflow и найди serials_recommendation_dag. Запусти его(автозапуск настроен на 20:00 каждый понедельник)

# Пример запроса к API:
{
  ["game of thrones", "shrinking"]
}
